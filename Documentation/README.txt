Wormhole Portal Offline Documentation
=====================================

Open index.html in a web browser. No web server or network connection is
required.

English documentation is located at the root. Korean documentation is
available from the language menu or at ko/index.html.

The packaged documentation uses only Team Beaver Studio HTML and CSS. It does
not include JavaScript, web fonts, icon libraries, third-party themes, or
network-loaded runtime assets.

The latest online documentation is available at:
https://teambeaverstudio.github.io/WormholePortal_Docs/
